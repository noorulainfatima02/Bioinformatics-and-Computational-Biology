## 🧬 Core Practical Projects & Research
Instead of just theoretical learning, I actively apply programming tools to biological datasets. Below are the implementations hosted within this repository:

*   **[`dna_analyzer.py`](./dna_analyzer.py) (DNA Sequence Analysis Tool):** A custom Python script designed to process raw DNA sequences, analyze GC-content, and locate foundational gene elements.
*   **[`covid19_genome_research.py`](./covid19_genome_research.py) (Viral Genome Parsing):** Code focused on automating the alignment or tracking of mutation vectors using structural genomic sequences.
*   **[`bioinfo_notebook.ipynb`](./bioinfo_notebook.ipynb) (Computational Biology Interactive Sandbox):** A comprehensive Jupyter Notebook capturing step-by-step biological data parsing, visualizing sequences, and checking sequence properties.
*   **[`embl_ebi_alignment.md`](./embl_ebi_alignment.md) & [`Research_Case_Study.md`](./Research_Case_Study.md):** Curated research notes and sequence alignments utilizing world-class databases like EMBL-EBI to evaluate biological data.
